자우니덱 실제 연결 베타 사용법

1. 컴퓨터와 휴대폰 또는 태블릿을 같은 와이파이에 연결합니다.
2. 컴퓨터에 Node.js LTS가 없다면 https://nodejs.org 에서 설치합니다.
3. Windows는 Start_Windows.bat, Mac은 Mac_실행.command를 실행합니다.
4. 화면에 표시된 “휴대폰/태블릿 주소”를 휴대폰 인터넷 브라우저에 입력합니다.
5. 컴퓨터 화면의 6자리 연결번호를 휴대폰에 입력합니다.
6. 버튼을 누르면 컴퓨터에서 실제 명령이 실행됩니다.

Mac 최초 설정
- 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 터미널을 허용해야 단축키와 문구 입력이 작동합니다.

Windows 방화벽
- 최초 실행 시 네트워크 허용 창이 나오면 “개인 네트워크”만 허용합니다.

현재 베타 범위
- 같은 와이파이에서만 연결됩니다.
- 단축키, 프로그램 실행, 문구 자동 입력, 음악·영상 제어를 지원합니다.
- 연결 프로그램 창을 닫으면 연결이 종료됩니다.
- 버튼을 길게 누르거나 우클릭하면 삭제할 수 있습니다.
